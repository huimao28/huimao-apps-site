微信通知进化
隐私政策

生效日期及最近更新：2026 年 11 月 19 日

微信通知进化是一款本地优先的通知增强工具。本政策依据当前仓库 README、Manifest 与相关源码描述真实处理边界。

1. 通知监听与核心处理

经你授予“通知使用权”后，应用监听微信（com.tencent.mm）通知，读取 CarExtender 会话数据或通知标题、正文、发送者、时间、头像及微信提供的操作入口，用于聚合会话、取消原通知并重发 MessagingStyle 进化通知。点击仍使用微信原 contentIntent；微信移除原通知时同步清理。

通知内容会在运行内存中形成会话。标准用户空间可按 UserHandle 隔离，但 ColorOS 等同 UserHandle 分身无法可靠区分。

2. 可选本地加密历史

历史记录默认关闭。开启后，只保存开启后成功生成进化通知时捕获到的消息；可能缺失或折叠，不是完整聊天备份。记录包含会话标题、发送者、正文和时间，并在应用私有数据库中加密保存，密钥由 Android Keystore 保护。

默认保留期为 7 天；你可调整保留期、排除会话、选择“排除并删除已有记录”、删除单个会话或清空全部记录。清空应用数据或卸载也会删除本地数据；allowBackup=false，不使用 Android 自动备份。

3. AI Provider：仅主动确认后传输

AI 总结默认不会自动运行，也默认不选会话。你必须配置自己的 OpenAI-compatible Provider、选择未被排除的会话及范围、预览将发送的原文，并再次确认；只有确认后才联网。

请求可能向你配置的 Provider 传输：所选会话标题、发送者、消息正文、时间/组织后的提示词，另含模型名；HTTP 请求还会携带 API Key（Bearer 凭据）及常规网络信息。Provider 会按其自身政策处理。应用只接受 HTTPS 443，不跟随重定向；总结结果仅驻留内存。API Key 经 Android Keystore AES‑GCM 加密保存在本机且不回显。

你主动测试连接时仅发送固定 ping，不发送聊天内容；主动刷新模型时会携带已保存 Key 请求 GET /models。删除 Provider 或清除 Key 可移除相应凭据。复制或分享原文、总结或诊断报告会把内容交给剪贴板或你选择的外部应用。

4. Android Auto、气泡与直达聊天

进化通知声明通知型 Android Auto 能力，向车机/Android Auto 展示 MessagingStyle 会话及微信提供的真实回复/已读入口。可选模拟兼容动作默认关闭：模拟已读只清除本地通知、内存会话与 shortcut；模拟回复只在当前进程本地回显，不发送微信、不持久化、不上传。

可选气泡直达/学习可能短暂打开微信并影响未读状态。应用不记录或上传微信 Main_User；映射在内存中，但直达所需值会作为 shortcut Intent extra 交给 Android，因此可能由 Launcher/系统保存在本机。shortcut ID 由私有随机盐和 HMAC 生成，无法由 ID 反推出原值。

5. 诊断、保活与本机数据

诊断报告包含应用/系统版本、权限和配置状态，不含聊天正文、联系人、Main_User、通知 key、Intent extras 或凭据。最近 20 条处理事件仅记录时间、来源用户编号和阶段枚举，留在进程内存，重启即清空。

可选后台保活默认关闭；开启后使用前台服务、常驻低优先级通知、JobScheduler 和开机/更新恢复来改善监听可用性，本身不进行数据传输。配置、会话身份盐、加密历史及 Provider 配置保存在应用私有存储。

6. 权限与第三方服务

  • 通知使用权：读取、取消并重组微信通知。
  • 发送通知：显示进化通知及可选保活通知。
  • 网络：仅用于用户确认后的 AI 请求、主动连接测试和模型刷新。
  • 前台服务、开机完成：仅用于用户开启的可选保活及恢复。
  • 气泡/Android Auto：由 Android、桌面、Google Android Auto、车机及微信共同处理和决定效果。

代码未集成广告、统计分析或崩溃遥测服务；应用不会将通知或历史发送到开发者服务器。第三方包括微信/腾讯、Android/Google Android Auto、你选择的 AI Provider，以及复制/分享时选择的应用。

7. 用户选择、儿童与联系

你可撤销通知使用权或通知权限，关闭并清空历史，设置排除项，关闭保活/气泡/模拟车机动作，清除 Provider Key，清除应用数据或卸载。应用不面向儿童，也不会有意收集儿童信息。

项目与腾讯无隶属或背书关系。隐私问题请通过 GitHub Issues 联系；请勿在公开 Issue 提交聊天内容或凭据。

如政策与应用行为发生重要变化，我们会更新本页及“最近更新”日期。
