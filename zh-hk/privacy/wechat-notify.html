微信通知進化
隱私權政策

生效日期及最近更新：2026 年 11 月 19 日

微信通知進化是一款本地優先的通知增強工具。本政策依據目前倉庫 README、Manifest 與相關原始碼描述真實處理邊界。

1. 通知監聽與核心處理

經你授予「通知使用權」後，應用監聽微信（com.tencent.mm）通知，讀取 CarExtender 會話資料或通知標題、正文、發送者、時間、頭像及微信提供的操作入口，用於聚合會話、取消原通知並重發 MessagingStyle 進化通知。點擊仍使用微信原 contentIntent；微信移除原通知時同步清理。

通知內容會在執行記憶體中形成會話。标准用户空间可按 UserHandle 隔离，但 ColorOS 等同 UserHandle 分身无法可靠区分。

2. 選用本地加密歷史

歷史記錄預設為關閉。開啟後，只儲存開啟後成功產生進化通知時捕獲到的訊息；可能缺失或折疊，而不是完整聊天備份。記錄包含會話標題、傳送者、正文和時間，並在應用程式私有資料庫中加密保存，金鑰由 Android Keystore 保護。

默认保留期为 7 天；你可调整保留期、排除会话、选择“排除并删除已有记录”、删除单个会话或清空全部记录。清空應用程式資料或卸載也會刪除本機資料；allowBackup=false，不使用 Android 自動備份。

3. AI Provider：僅主動確認後傳輸

AI 總結預設不會自動執行，也預設不選會話。你必須配置自己的 OpenAI-compatible Provider、選擇未被排除的會話及範圍、預覽將發送的原文，並再次確認；只有確認後才連網。

請求可能傳送給你的 Provider ：所選會話標題、傳送者、訊息內文、時間/組織後的提示詞，另含模型名；HTTP 請求也會攜帶 API Key（Bearer 憑證）及常規網路資訊。 Provider 會依其自身政策處理。應用程式只接受 HTTPS 443，不跟隨重定向；總結結果僅駐留記憶體。 API Key 經 Android Keystore AES‑GCM 加密儲存於本機且不回顯。

你主動測試連線時僅發送固定 ping，不發送聊天內容；主動刷新模型時會攜帶已儲存 Key 請求 GET /models。删除 Provider 或清除 Key 可移除相应凭据。复制或分享原文、总结或诊断报告会把内容交给剪贴板或你选择的外部应用。

4. Android Auto、氣泡與直達聊天

進化通知聲明通知型 Android Auto 能力，向車機/Android Auto 展示 MessagingStyle 會話及微信提供的真實回覆/已讀入口。選用模擬相容動作預設關閉：模擬已讀只清除本機通知、記憶體會話與 shortcut；類比回覆只在目前行程本機回顯，不傳送微信、不持久化、不上傳。

可選氣泡直達/學習可能短暫打開微信並影響未讀狀態。應用程式不記錄或上傳微信 Main_User;映射在記憶體中，但直達所需值會作為 shortcut Intent extra 交給 Android，因此可能由 Launcher/系統保存在本機。 shortcut ID 由私人隨機鹽和 HMAC 生成，無法由 ID 反推出原值。

5. 診斷、保活與本機數據

診斷報告包含應用程式/系統版本、權限和設定狀態，不含聊天正文、聯絡人、Main_User、通知 key、Intent extras 或憑證。最近 20 個處理事件僅記錄時間、來源使用者編號和階段枚舉，留在進程內存，重啟即清空。

選用後台保活預設關閉；開啟後使用前台服務、常駐低優先通知、JobScheduler 和開機/更新恢復來改善監聽可用性，本身不進行資料傳輸。配置、會話身份鹽、加密歷史及 Provider 配置保存在應用私有儲存中。

6. 權限與第三方服務

  • 通知使用權：讀取、取消並重組微信通知。
  • 發送通知：顯示進化通知及可選保活通知。
  • 網路：僅用於使用者確認後的 AI 請求、主動連線測試和模型刷新。
  • 接待櫃檯服務、開機完成：僅用於用戶開啟的選用保活及恢復。
  • 氣泡/Android Auto：由 Android、桌上型電腦、Google Android Auto、車機及微信共同處理決定效果。

程式碼未整合廣告、統計分析或崩潰遙測服務；應用程式不會將通知或歷史傳送到開發者伺服器。第三方包括微信/騰訊、Android/Google Android Auto、你選擇的 AI Provider，以及複製/分享時選擇的應用。

7. 使用者選擇、兒童與聯繫

你可撤銷通知使用權或通知權限，關閉並清空歷史，設定排除項，關閉保活/氣泡/模擬車機動作，清除 Provider Key，清除應用資料或卸載。應用不面向兒童，也不會有意收集兒童資訊。

項目與騰訊無隸屬或背書關係。隱私問題請透過 GitHub Issues 聯絡；請勿在公開 Issue 提交聊天內容或憑證。

如政策與應用行為有重要變化，我們會更新本頁及「最近更新」日期。
