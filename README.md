# 灰猫应用官网

Material 3 Expressive 风格的纯静态产品官网，无构建依赖、无外部 CDN。展示灰猫地图、GhostTrack、灰猫车管与微信通知进化。

## 本地预览

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000/`。

## GitHub Pages

仓库已包含 `.github/workflows/pages.yml`。在仓库 Settings → Pages 中将 Source 设为 **GitHub Actions**，推送到 `main` 后即可部署。所有站内资源使用相对路径，支持项目子路径。

## 内容依据

灰猫地图和微信通知进化描述取自随素材提供的仓库 README；GhostTrack 与灰猫车管仅按宣传素材名作谨慎概括。隐私细节如与当前应用版本不同，以应用内说明及对应 Google Play 页面为准。
